Estrategia de Cancelación en Multiplicación y División

La clave en 4to Bachillerato es FACTORIZAR PRIMERO antes de multiplicar para simplificar fácilmente:

✖️ Multiplicación Directa

Se multiplican numeradores en línea recta y denominadores en línea recta:

(A / B) × (C / D) = (A ċ C) / (B ċ D)

➗ División por Inverso

Se invierte la segunda fracción (el divisor) y se convierte en multiplicación:

(A / B) ÷ (C / D) = (A / B) × (D / C)

Ejemplo 1: Multiplicación con Factorización Previa

Operamos [(x² - 9) / (x + 2)] × [(x + 2) / (x - 3)] cancelando factores idénticos:

📋 Procedimiento Resuelto Paso a Paso:

Paso 1 (Factorizar x² - 9): Diferencia de cuadrados x² - 9 = (x - 3)(x + 3).
Paso 2 (Escribir producto de factores): = [ (x - 3)(x + 3)(x + 2) ] / [ (x + 2)(x - 3) ]
Paso 3 (Cancelar factores comunes x-3 y x+2): Queda únicamente el factor (x + 3).
Resultado Final Simplificado: = x + 3

Ejemplo 2: División de Fracciones Algebraicas

Calculamos [(x² + 2x) / 5] ÷ [(x + 2) / 10] invirtiendo el segundo término:

📋 Procedimiento Resuelto Paso a Paso:

Paso 1 (Invertir divisor y factorizar x²+2x): = [ x(x + 2) / 5 ] × [ 10 / (x + 2) ]
Paso 2 (Agrupar numeradores y denominadores): = [ 10 ċ x(x + 2) ] / [ 5 ċ (x + 2) ]
Paso 3 (Cancelar (x + 2) y simplificar 10/5): 10 / 5 = 2. Queda 2 ċ x.
Resultado Final Simplificado: = 2x

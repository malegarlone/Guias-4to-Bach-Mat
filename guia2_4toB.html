Leyes de Exponentes y Productos Notables

Fórmulas algebraicas clave para elevar binomios a potencias sin realizar multiplicaciones extensas:

Binomio al Cuadrado

(a + b)² = a² + 2ab + b²

Cuadrado del primero + doble producto + cuadrado del segundo.

Binomio al Cubo

(a + b)³ = a³ + 3a²b + 3ab² + b³

Triple producto alternado por potencias decrecientes.

Exponentes Racionales

x^(m/n) = √[n](x^m)

El numerador es el exponente y el denominador la raíz.

Ejemplo 1: Potenciación de un Binomio (2x + 3)²

Aplicamos el producto notable del binomio al cuadrado paso a paso de corrido:

📋 Procedimiento Resuelto Paso a Paso:

Paso 1 (Identificar a y b): Sea a = 2x y b = 3. Aplicar fórmula (a + b)² = a² + 2ab + b².
Paso 2 (Sustituir términos): = (2x)² + 2(2x)(3) + (3)²
Paso 3 (Resolver exponentes y productos): (2x)² = 4x²  ;  2(2x)(3) = 12x  ;  3² = 9
Resultado Final Desarrollado: = 4x² + 12x + 9

Ejemplo 2: Radicación y Extracción de Factores

Simplificamos el radical $\sqrt{18x^5 y^6}$ convirtiendo exponentes a potencias pares divisibles entre la raíz cuadrada ($n = 2$):

📋 Procedimiento Resuelto Paso a Paso:

Paso 1 (Descomponer radicando): 18 = 9 × 2  ;  x&sup5; = x&sup4; ċ x  ;  y&sup6; es par.
Paso 2 (Agrupar factores fuera del radical): √(9 ċ x&sup4; ċ y&sup6; ċ 2 ċ x)
Paso 3 (Extraer raíces exactas): √9 = 3  ;  √(x&sup4;) = x²  ;  √(y&sup6;) = y³
Resultado Final Simplificado: = 3x²y³ √(2x)

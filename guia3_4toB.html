Mínimo Común Múltiplo (MCM) de Denominadores

Para sumar o restar fracciones algebraicas con distinto denominador, debemos llevarlas a un común denominador (MCM):

1°) Denominadores Iguales

Se mantiene el mismo denominador y simplemente se operan los numeradores:

(A / D) + (B / D) = (A + B) / D

2°) Denominadores Distintos (MCM)

Factorizar denominadores y formar el MCM con los factores comunes y no comunes de mayor exponente:

MCM(x - 2, x² - 4) = (x - 2)(x + 2)

Ejemplo 1: Suma con Mismo Denominador

Operamos los numeradores directamente agrupando términos semejantes:

📋 Procedimiento Resuelto: (3x / x+1) + (5 / x+1)

Paso 1 (Unir numeradores): = (3x + 5) / (x + 1)
Paso 2 (Verificar si se puede simplificar): 3x + 5 no comparte factores con x + 1.
Resultado Final Irreducible: = (3x + 5) / (x + 1)

Ejemplo 2: Resta con Distinto Denominador (MCM)

Efectuamos la resta [3 / (x - 1)] - [2 / (x + 1)] hallando el MCM de denominadores:

📋 Procedimiento Resuelto Paso a Paso:

Paso 1 (MCM de denominadores): MCM = (x - 1)(x + 1) = x² - 1.
Paso 2 (Homogeneizar numeradores): [3(x + 1) - 2(x - 1)] / (x - 1)(x + 1)
Paso 3 (Distribuir y reducir numeradores): = (3x + 3 - 2x + 2) / (x - 1)(x + 1)
Resultado Final Simplificado: = (x + 5) / (x² - 1)
